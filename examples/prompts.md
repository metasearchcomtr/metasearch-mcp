# Prompt recipes

## Google Hotel Center

```text
Validate this feed for Google Hotel Center. Group issues by code, show affected row numbers, and give me the minimum source-data fixes.
```

## Cross-platform reuse

```text
Compare this feed for Google Hotel Center, Wego and trivago. Show fields that can stay canonical and fields that need platform-specific mapping.
```

## Normalize first

```text
Detect the feed format, normalize the records to the canonical hotel model, then validate them for Wego.
```
