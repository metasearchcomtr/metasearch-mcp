# Getting started

The metasearch MCP server is hosted remotely. You do not need to clone this repository or run a local server.

Endpoint:

```text
https://metasearch.com.tr/mcp
```

Recommended first prompt:

```text
List the metasearch feed-validation tools you can use, then explain which validator is appropriate for a Google Hotel Center Hotel List CSV.
```

For concrete client configuration, see [client-setup.md](client-setup.md).
